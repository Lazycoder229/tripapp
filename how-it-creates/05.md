## Creating Middleware Pipilines

# Create  MiddlewareInterface.php
```bash
Gagawa tayo ng kontrata o interface na dapat sundin ng lahat ng middleware mo. Ang bawat middleware ay makakatanggap ng $request at isang $next handler (na kumakatawan sa susunod na middleware o sa mismong controller).
Gumawa ng file sa src/Http/Middleware/MiddlewareInterface.php:
```

```php
<?php

declare(strict_types=1);

namespace Framework\Http\Middleware;

use Framework\Http\Request;
use Framework\Http\Response;
/**
 * MiddlewareInterface defines the contract for middleware classes in the application.
 * Middleware classes implementing this interface must provide a handle method that processes
 * A Request object and returns a Response object. This allows for flexible request handling and response generation in the application.
 * @package Framework\Http\Middleware
 * 
 */
interface MiddlewareInterface
{
    /**
     * Executes the middleware logic.
     * Must return a Response object.
     */
    public function handle(Request $request, callable $next): Response;
}

```
## Create Pipelines.php
```bash
Ang Pipeline class ang may trabahong pagtagpi-tagpiin ang mga middlewares at ang controller method para maging isang tuluy-tuloy na kadena (chain). Gagamit tayo ng native PHP array_reduce para sa malinis na implementasyon.
Gumawa ng file sa src/Framework/Http/Pipeline.php:
```

```php
<?php

declare(strict_types=1);

namespace Framework\Http\Pipeline;

use Framework\Http\Request;
use Framework\Http\Response;
use Framework\Container\Container;
use Framework\Http\Middleware\MiddlewareInterface;
use Exception;

/**
 * Pipeline class
 * A pipeline is a series of middleware that process an HTTP request before it reaches the final destination (usually a controller).
 * This class allows you to add middleware to the pipeline and execute them in order.
 * @package Framework\Http\Pipeline
 */
final class Pipeline
{
    private array $middlewares = [];

    public function __construct(
        private Container $container
    ) {
    }

    /**
     * Adds middlewares to the pipeline
     * @param array $middlewares
     * @return self
     */
    public function pipe(array $middlewares): self
    {
        // Merge the new middlewares with the existing ones
        $this->middlewares = array_merge($this->middlewares, $middlewares);
        return $this;
    }

    /**
     * Processes the pipeline with the given request and destination
     * @param Request $request
     * @param callable $destination
     * @return Response
     */
    public function process(Request $request, callable $destination): Response
    {
        // Reverse the array to ensure correct order from first to last middleware
        $middlewares = array_reverse($this->middlewares);

        // The core mechanism using array_reduce to wrap each middleware around the next
        $pipeline = array_reduce(
            $middlewares,
            function (callable $next, string $middlewareClass) {
                return function (Request $request) use ($next, $middlewareClass): Response {
                    // Get the middleware instance from your custom DI Container!
                    $middlewareInstance = $this->container->get($middlewareClass);
                    // Ensure the middleware implements the MiddlewareInterface
                    if (!$middlewareInstance instanceof MiddlewareInterface) {
                        throw new Exception("Pipeline Error: Ang '{$middlewareClass}' ay dapat mag-implement ng MiddlewareInterface.");
                    }

                    // Execute the handle method of the middleware
                    return $middlewareInstance->handle($request, $next);
                };
            },
            $destination // The final destination callable that will be executed after all middlewares
        );

        return $pipeline($request);
    }
}
```

## Update ang Router.php at Application.php

```bash
Ngayon, kailangan nating payagan ang framework na tumanggap ng Global Middlewares (tumatakbo sa lahat ng ruta).
1. I-update ang Application.phpMagdaragdag tayo ng static array $middlewares at isang registerMiddleware() method para makapag-salpak ng global middlewares sa index.php.
```

```php
// Idagdag ang mga gawa nating namespaces sa itaas ng Application.php
use Framework\Http\Pipeline\Pipeline;

final class Application
{
    private static array $controllers = [];
    private static array $middlewares = []; // Imbakan ng global middlewares

    private function __construct(){}

    // ... panatilihin ang autoDiscoverControllers at registerController ...

    /**
     * Public API para magrehistro ng Global Middlewares mula sa index.php
     */
    public static function registerMiddleware(string $middlewareClass): void
    {
        self::$middlewares[] = $middlewareClass;
    }

    public static function run(string $controllersPath, string $controllersNamespace): void
    {
        $container = new Container();
        $router = new Router($container);

        self::autoDiscoverControllers($controllersPath, $controllersNamespace, $router);

        $request = Request::createFromGlobals();

        try {
            // Gumawa ng Pipeline at i-pipe ang mga global middlewares
            $pipeline = new Pipeline($container);
            $pipeline->pipe(self::$middlewares);

            // Patakbuhin ang pipeline. Ang destination callback ay ang dating router dispatch!
            $response = $pipeline->process($request, function (Request $request) use ($router): Response {
                return $router->dispatch($request);
            });

        } catch (\Exception $e) {
            $response = new Response("<h1>Framework Critical Error</h1><p>{$e->getMessage()}</p>", 500);
        }

        $response->send();
    }
}

```
## Register to public/index.php

```php
<?php
declare(strict_types=1);

require_once __DIR__ . '/../vendor/autoload.php'; 

use Framework\Application;
use App\Middleware\AuthMiddleware;

// 1. Irehistro ang iyong global middleware
Application::registerMiddleware(AuthMiddleware::class);

// 2. Patakbuhin ang app gaya ng dati
Application::run(
    controllersPath: __DIR__ . '/../app/Controller', 
    controllersNamespace: 'App\\Controller'
);

```
## Testing Your New Pipeline API
```bash
Gagawa tayo ng isang halimbawa ng middleware na magsisilbing proteksyon ng iyong application.
1. Gumawa ng AuthMiddleware.phpHalimbawa, haharangin natin ang request kung walang tamang api_token sa URL.Gumawa nito sa app/Middleware/AuthMiddleware.php
```
```php
<?php

namespace App\Middleware;

use Framework\Http\Middleware\MiddlewareInterface;
use Framework\Http\Request;
use Framework\Http\Response;

class AuthMiddleware implements MiddlewareInterface
{
    public function handle(Request $request, callable $next): Response
    {
        // 1. ISULAT ANG MIDDLEWARE LOGIC (BAGO MAKAPASOK SA CONTROLLER)
        $token = $request->query('token');

        if ($token !== 'secret123') {
            // Haharangin ang request at magbabalot agad ng error response!
            return Response::json(['error' => 'Unauthorized: Invalid or missing token.'], 401);
        }

        // 2. PATULOY SA SUSUNOD (Ipasa ang request sa susunod na middleware o controller)
        return $next($request);
    }
}
```
