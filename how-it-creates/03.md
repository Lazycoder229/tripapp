### CREATING DI FROM SCRATCH 
So we dont need to manually call the Controller and Services.

## CREATE Container
```bash
Create this file at src/Container/Container.php. Notice that it doesn't implement or use any external code.
```
## Put this inside the Container.php
```php
<?php

declare(strict_types=1);

namespace Framework\Container;

use ReflectionClass;
use ReflectionParameter;
use Exception;

/**
 * Pure PHP Dependency Injection Container built from scratch.
 * Handles configuration storage and automated dependency resolution (Auto-wiring).
 * 
 * @package Framework\Container
 */
final class Container
{
    /**
     * Stores configuration values, primitives, or cached shared singleton instances.
     */
    private array $entries = [];

    /**
     * Manually register a service, configuration value, or a factory closure.
     */
    public function set(string $id, mixed $value): void
    {
        $this->entries[$id] = $value;
    }

    /**
     * Retrieve a service instance. Automatically auto-wires class dependencies.
     */
    public function get(string $id): mixed
    {
        // 1. If manually bound or already resolved as a singleton, return it
        if (isset($this->entries[$id])) {
            // If it is a factory function, execute it first
            if (is_callable($this->entries[$id]) && !($this->entries[$id] instanceof \Closure === false)) {
                $this->entries[$id] = call_user_func($this->entries[$id], $this);
            }
            return $this->entries[$id];
        }

        // 2. If it doesn't exist in entries, check if it's an existing class we can auto-wire
        if (!class_exists($id)) {
            throw new Exception("Container Error: Entry or Class '{$id}' could not be found.");
        }

        return $this->resolve($id);
    }

    /**
     * Checks if the container can provide an entry for the given ID.
     */
    public function has(string $id): bool
    {
        return isset($this->entries[$id]) || class_exists($id);
    }

    /**
     * The Auto-wiring mechanism engine using PHP Reflection API.
     */
    private function resolve(string $className): mixed
    {
        $reflectionClass = new ReflectionClass($className);

        // Make sure we can actually instantiate the class
        if (!$reflectionClass->isInstantiable()) {
            throw new Exception("Container Error: Class '{$className}' is not instantiable (Abstract or Interface).");
        }

        $constructor = $reflectionClass->getConstructor();

        // If there is no constructor, it has no dependencies! Instantiate immediately.
        if ($constructor === null) {
            return new $className();
        }

        // Inspect the constructor parameters
        $parameters = $constructor->getParameters();
        $dependencies = [];

        foreach ($parameters as $parameter) {
            $dependencies[] = $this->resolveParameter($parameter, $className);
        }

        // Create the instance, passing the resolved dependencies into the constructor
        $instance = $reflectionClass->newInstanceArgs($dependencies);

        // Cache it as a singleton so we don't recreate it on subsequent calls
        $this->entries[$className] = $instance;

        return $instance;
    }

    /**
     * Deduce and resolve what dependency a constructor parameter is asking for.
     */
    private function resolveParameter(ReflectionParameter $parameter, string $className): mixed
    {
        $type = $parameter->getType();

        // Case A: Missing type-hint entirely (e.g., public function __construct($someVariable))
        if ($type === null) {
            if ($parameter->isDefaultValueAvailable()) {
                return $parameter->getDefaultValue();
            }
            throw new Exception("Container Error: Cannot resolve untyped parameter '\${$parameter->getName()}' in {$className}.");
        }

        // Case B: Primitive/Built-in types (e.g., string, int, bool)
        if ($type->isBuiltin()) {
            if ($parameter->isDefaultValueAvailable()) {
                return $parameter->getDefaultValue();
            }
            throw new Exception("Container Error: Parameter '\${$parameter->getName()}' in {$className} expects a built-in '{$type->getName()}', but no default value is set.");
        }

        // Case C: The type-hint is an Object/Class name (e.g., App\Service\DatabaseService)
        // Recursively trigger the container's get() method to build that class next!
        return $this->get($type->getName());
    }
}

```

##  UPDATE THE Router.php to use the Container
```bash
Now, update your framework classes to pass and accept your new custom container.1. Update Router.phpChange the type-hint of the container in the constructor to use your custom container namespace.
```
```php
<?php

declare(strict_types=1);

namespace Framework\Routing;

use Framework\Routing\Attribute\Route;
use Framework\Container\Container; // Import your custom container
use ReflectionClass;
use Exception;

final class Router
{
    // Type-hint your pure Container class
    public function __construct(
        private Container $container,
        private array $routes = []
    ) {
    }   

    // ... Keep your registerController and addRoute methods exactly as they are ...

    public function dispatch(string $requestUri, string $requestMethod): mixed
    {
        $parsedUrl = parse_url($requestUri, PHP_URL_PATH);
        $path = '/' . trim($parsedUrl, '/');
        $method = strtoupper($requestMethod);

        foreach ($this->routes as $route) {
            if ($route['method'] === $method && preg_match($route['regex'], $path, $matches)) {
                array_shift($matches);
                $parameters = $matches;
                $handler = $route['handler'];

                if (is_callable($handler)) {
                    return call_user_func_array($handler, $parameters);
                }

                if (is_array($handler)) {
                    [$controllerClass, $methodName] = $handler;
                    
                    // The custom container resolves the controller and its dependencies
                    $controllerInstance = $this->container->get($controllerClass);
                    
                    return call_user_func_array([$controllerInstance, $methodName], $parameters);
                }
            }
        }

        http_response_code(404);
        throw new Exception("404 Not Found: No route found for {$method} {$path}");
    }
}

```

## Update the Application.php to register the new Router
```bash
Instantiate your new Container class right at the start of your application runtime process.
```

```php
<?php

declare(strict_types=1);

namespace Framework;

use Framework\Routing\Router;
use Framework\Container\Container; // Import our custom container
use RecursiveDirectoryIterator;
use RecursiveIteratorIterator;
use Exception;

final class Application
{
    private function __construct(){}

    // ... Keep your autoDiscoverControllers method exactly as it is ...

    public static function run(string $controllersPath, string $controllersNamespace): void
    {
        // 1. Initialize your custom container from scratch
        $container = new Container();

        // 2. Feed it into your Router
        $router = new Router($container);

        self::autoDiscoverControllers($controllersPath, $controllersNamespace, $router);

        try {
            $requestUri = $_SERVER['REQUEST_URI'] ?? '/';
            $requestMethod = $_SERVER['REQUEST_METHOD'] ?? 'GET';

            $response = $router->dispatch($requestUri, $requestMethod);

            if (is_string($response)) {
                echo $response;
            } elseif (is_array($response) || is_object($response)) {
                header('Content-Type: application/json');
                echo json_encode($response);
            }

        } catch (Exception $e) {
            echo "<h1>Framework Error</h1><p>" . $e->getMessage() . "</p>";
        }
    }
}

```

```bash
To test your pure container, create a dependency service class at app/Service/ConfigService.php
```

```php
namespace App\Service;

class ConfigService
{
    public function getAppName(): string
    {
        return "My Custom Scratch Framework";
    }
}

```

```bash
If you run your application now and hit GET /, you will see a JSON array output displaying your application name. You have built a fully capable reflection-based DI container engine entirely on your own.
```
