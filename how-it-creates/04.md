## Writing custom HTTP Request and Response abstraction wrappers from scratch

```bash
Let’s write the HTTP Request and Response abstraction wrappers completely from scratch with absolutely zero external libraries.These classes will replace direct interactions with messy PHP superglobals like $_SERVER, $_POST, and $_GET, as well as procedural functions like header() and echo. This architecture makes your controllers infinitely cleaner, more secure, and ready for advanced setups like the PHP Fibers or asynchronous loops we talked about at the beginning.

Step 1: Create the Request.php ClassCreate this file at src/Framework/Http/Request.php. This class object captures and normalizes all incoming data, query strings, post parameters, and raw payload requests (like JSON APIs).
```

```php
<?php

declare(strict_types=1);

namespace Framework\Http;

/**
 * Custom Request Abstraction from Scratch
 * This class encapsulates HTTP request data, providing methods to access query parameters, request body data, and server information.
 * It also supports method spoofing for HTML forms and JSON payloads for API requests.
 * @package Framework\Http
 */
final class Request
{
    public function __construct(
        private array $query,
        private array $body,
        private array $server,
        private ?string $rawContent = null
    ) {
    }

    /**
     * Factory method to boot a Request object up using native PHP global boundaries
     * 
     * @return self Returns a new instance of the Request class populated with global request data.
     */
    public static function createFromGlobals(): self
    {
        // Capture the global request data
        $body = $_POST;
        $server = $_SERVER;
        $method = strtoupper($server['REQUEST_METHOD'] ?? 'GET');

        // Support HTML Form Method Spoofing (For matching PUT, PATCH, DELETE routes via Forms)
        if ($method === 'POST' && isset($_POST['_method'])) {
            $server['REQUEST_METHOD'] = strtoupper($_POST['_method']);
            $method = $server['REQUEST_METHOD'];
        }

        // Support native JSON API payload streams
        $rawContent = file_get_contents('php://input');
        if ($method !== 'GET' && !empty($rawContent)) {
            $jsonData = json_decode($rawContent, true);
            if (is_array($jsonData)) {
                $body = array_merge($body, $jsonData);
            }
        }
        // Return a new Request instance populated with the captured data
        return new self($_GET, $body, $server, $rawContent ?: null);
    }

    /**
     * Get the current request path (URI) without query parameters.
     * @return string Returns the request path, e.g., "/users/123".
     */
    public function getPath(): string
    {
        // Extract the path from the REQUEST_URI, ignoring query parameters
        $uri = $this->server['REQUEST_URI'] ?? '/';
        $parsedUrl = parse_url($uri, PHP_URL_PATH);
        return '/' . trim($parsedUrl ?: '/', '/');
    }

    /**
     * Get the HTTP method of the current request (GET, POST, PUT, DELETE, etc.).
     * @return string Returns the HTTP method in uppercase.
     */
    public function getMethod(): string
    {
        // Return the HTTP method, defaulting to GET if not set
        return strtoupper($this->server['REQUEST_METHOD'] ?? 'GET');
    }

    /**
     * Fetch from URL Query Params ($_GET)
     */
    public function query(string $key, mixed $default = null): mixed
    {
        // Return the value from the query parameters if it exists, otherwise return the default value
        return $this->query[$key] ?? $default;
    }

    /**
     * Fetch from Request Body ($_POST or parsed JSON payloads)
     */
    public function input(string $key, mixed $default = null): mixed
    {
        // Return the value from the request body if it exists, otherwise return the default value
        return $this->body[$key] ?? $default;
    }

    /**
     * Merge and dump all input arrays
     */
    public function all(): array
    {
        // Merge query parameters and request body data into a single array and return it
        return array_merge($this->query, $this->body);
    }
}

```
## Create the Response.php Class
```bash
Create this file at src/Http/Response.php. Instead of echoing values instantly, controllers will return this payload package containing content, headers, and status codes.
```
```php
<?php

declare(strict_types=1);

namespace Framework\Http;

/**
 * This class encapsulates HTTP response data, providing methods to set the response content, status code, and headers.
 * It also includes a named constructor for JSON responses and a method to send the response to the client.
 * @package Framework\Http
 */
class Response
{
    public function __construct(
        protected mixed $content,
        protected int $statusCode = 200,
        protected array $headers = []
    ) {
    }

    /**
     * Named constructor helper for rendering sleek JSON payloads cleanly
     * @param array|object $data The data to be encoded as JSON.
     * @param int $statusCode The HTTP status code for the response.
     * @return self Returns a new instance of the Response class with the JSON content.
     */
    public static function json(array|object $data, int $statusCode = 200): self
    {
        // Return a new Response instance with JSON-encoded content, status code, and appropriate headers
        return new self(
            json_encode($data),
            $statusCode,
            ['Content-Type' => 'application/json']
        );
    }

    /**
     * Sends the complete HTTP payload out to the browser client interface
     * @return void
     * @param void
     */
    public function send(): void
    {
        // 1. Send the primary standard HTTP Status Code
        http_response_code($this->statusCode);

        // 2. Loop and attach all custom HTTP headers safely
        foreach ($this->headers as $name => $value) {
            header("{$name}: {$value}");
        }

        // 3. Emit the final content buffer block
        echo $this->content;
    }
}
```

## Wire Request & Response into Router and Application
```bash
Now, let's tie them together so your framework captures a Request at the start and finishes by firing a Response.1. Update Router.php (The dispatch method)Modify the dispatch process to take the entire Request entity object instead of raw strings, and ensure it passes the $request context directly into your controllers.
```
```php
// Add these namespaces at the top of src/Framework/Routing/Router.php
use Framework\Http\Request;
use Framework\Http\Response;

// Update the dispatch method declaration block:
public function dispatch(Request $request): Response
{
    $path = $request->getPath();
    $method = $request->getMethod();

    foreach ($this->routes as $route) {
        if ($route['method'] === $method && preg_match($route['regex'], $path, $matches)) {
            array_shift($matches);
            $parameters = $matches;
            
            // Push the Request instance as the very first argument for your controller methods
            array_unshift($parameters, $request);

            $handler = $route['handler'];

            if (is_callable($handler)) {
                $response = call_user_func_array($handler, $parameters);
            } elseif (is_array($handler)) {
                [$controllerClass, $methodName] = $handler;
                $controllerInstance = $this->container->get($controllerClass);
                $response = call_user_func_array([$controllerInstance, $methodName], $parameters);
            }

            // Normalization: Ensure a structural Response object always returns
            if ($response instanceof Response) {
                return $response;
            }

            if (is_array($response) || is_object($response)) {
                return Response::json($response);
            }

            return new Response((string) $response);
        }
    }

    return new Response("404 Not Found: No route found for {$method} {$path}", 404);
}
```

## Update Application.php (The run method)
```bash
Simplify the static runner method. It should capture globals, trigger the router pipeline, and immediately fire off the built wrapper response.
```

```php
// Add these namespaces at the top of src/Framework/Application.php
use Framework\Http\Request;
use Framework\Http\Response;

// Update the run method block:
public static function run(string $controllersPath, string $controllersNamespace): void
{
    $container = new Container();
    $router = new Router($container);

    self::autoDiscoverControllers($controllersPath, $controllersNamespace, $router);

    // 1. Build the Request abstraction lifecycle state out of global buffers
    $request = Request::createFromGlobals();

    try {
        // 2. Dispatch the Request down to the mapped matching route
        $response = $router->dispatch($request);
    } catch (\Exception $e) {
        $response = new Response("<h1>Framework Critical Error</h1><p>{$e->getMessage()}</p>", 500);
    }

    // 3. Emit the final payload response headers and output content out to the user
    $response->send();
}
```

### Writing clean Controller endpoints
```bash
Now, your controller methods are decoupled from globals! They can cleanly receive the Request payload object wrapper and explicitly return strings, structural arrays, or specialized Response objects.Update your HomeController.php to look like this:
```

```php
<?php

declare(strict_types=1);

namespace App\Controller;

use Framework\Routing\Attribute\Route;
use Framework\Http\Request;   // Import Request
use Framework\Http\Response;  // Import Response

class HomeController
{
    #[Route('/', 'GET')]
    public function index(Request $request): string
    {
        // Safe query filtering: /?user=Alex -> "Welcome back, Alex"
        $user = $request->query('user', 'Guest');
        return "Welcome to the home page, " . htmlspecialchars($user);
    }

    #[Route('/api/submit', 'POST')]
    public function apiStore(Request $request): Response
    {
        $email = $request->input('email');
        $role  = $request->input('role', 'subscriber');

        if (!$email) {
            // Emits standard JSON payload structure alongside a bad request header validation code
            return Response::json(['error' => 'Email is a required field'], 400);
        }

        // Returns an absolute JSON structural status with a 201 Created state code
        return Response::json([
            'success' => true,
            'received' => [
                'email' => $email,
                'role'  => $role
            ]
        ], 201);
    }
}
```
