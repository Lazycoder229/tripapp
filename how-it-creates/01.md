# Gumawa ng src/Application.php
```php
<?php
declare(strict_types=1);

namespace Framework;
/**
 * Application class
 * 
 * Start point of the application. It is responsible for bootstrapping the application and running it.
 * 
 * @package Framework
 */
final class Application
{
    /**
     * Private constructor to prevent instantiation of the Application class.
     */
    private function __construct(){}

    /**
     * Run the application.
     * The public static method that is called to start the application.
     *  It can be used to initialize the application, set up dependencies, and handle requests.
     * @return void
     */
    public static function run():void
    {
        echo "Application is running";
    }
}
```
## Gumawa ng /index.php
```php
<?php

require_once __DIR__ . '/../vendor/autoload.php';

use Framework\Application;

Application::run();
```
